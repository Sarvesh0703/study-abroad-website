# US Admissions — React Website

A responsive admissions landing page built with React, Vite, and Lucide icons.

## Run locally

1. Install Node.js (recommended: Node 20 or newer).
2. Open this folder in VS Code / terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Included

- Responsive desktop navigation and animated mobile slide-in sidebar
- Hero section with image collage
- Four-step admissions process
- Study areas and work-opportunity information
- About / Why study in the USA section
- Interactive FAQ accordion
- Responsive counselling form with front-end validation and demo success state
- Footer, social links and back-to-top control

## Before publishing

- Replace demo email and phone details with your real contact details.
- Connect the counselling form to your backend, CRM, or form service. The current form only displays a demo confirmation.
- Update login links and social links to your actual destinations.
- Review all visa/work-authorisation information with a qualified professional before publishing.
- The page uses remote Unsplash images and Google Fonts; download and self-host assets if you need fully local assets.
